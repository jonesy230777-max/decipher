# Decipher · Demo

A self-contained snapshot of the Decipher sales-DNA platform. One command boots Postgres, Mailpit, the API, the dashboard, and seeds the database with a real demo dataset (5 companies, ~14 teams, ~430 respondents, ~400 audits, 2 fully scored Media-Sales-v1 reports).

## What you need

| | Minimum | Get it |
|---|---|---|
| **macOS or Linux** | macOS 13+ or any modern Linux | — |
| **Docker Desktop** | running | <https://www.docker.com/products/docker-desktop> |
| **Python** | 3.12+ | <https://www.python.org> |
| **Node.js** | 18+ | <https://nodejs.org> |

Windows users: WSL2 with Ubuntu works. Native Windows is not supported.

## Run it

```bash
unzip decipher-demo.zip
cd Decipher
./demo/run-demo.sh
```

The script is interactive. It will:

1. **Check prerequisites** — fails fast with install links if anything's missing.
2. **Resolve free ports** — auto-picks ports if 55432/58080/55173/58025 are busy.
3. **Start Postgres + Mailpit** via `docker compose`.
4. **Load the demo snapshot** (1.5 MB SQL dump → ~430 respondents, ~400 audits, scored reports, narratives).
5. **Install Python + Node deps** (one-time, ~1 minute).
6. **Launch API + dashboard** and offer to open the browser.

End-state: dashboard at <http://127.0.0.1:55173> (or whichever port was free).

## What to try

Start as **admin** for the full surface; then switch roles to see the scoping in action.

1. **Mission Control** (`/`) — the time-controllable executive view. Switch the range to 30d/6mo/12mo to see history.
2. **Companies → Atlas Media Group** — drill from a company into its teams and executives.
3. **Teams → Metro Sales Team** — the executive dashboard mirroring the original mockup slide.
4. **Respondents → Owen Wright → Grant Smith** — the "SD drills into a rep" user story end-to-end.
5. **Audits** — filter by **Version = Media Sales v1** to see the only fully scored audits.
6. **Funnel** — send a real audit invite to your own email; it lands in **Mailpit** (link at top of screen).
7. **Take an audit yourself** — `/audit/start`, answer 34 questions, see the live score + PDF download + emailed report.
8. **Settings → Scoring engine** — at-a-glance health of the scoring chain (taxonomy, narratives, last delivery).

## Stopping / restarting

```bash
./demo/stop-demo.sh    # stops everything, preserves DB volume
./demo/run-demo.sh     # restart later, picks up where you left off
```

## Resetting to a clean state

```bash
./demo/stop-demo.sh
docker volume rm decipher_postgres_data  # wipes the DB
./demo/run-demo.sh                       # re-loads from the snapshot
```

## Where things live

```
demo/
├─ run-demo.sh         interactive bootstrap (this script)
├─ stop-demo.sh        clean shutdown
├─ decipher_dump.sql   the demo dataset snapshot (loaded on first boot)
└─ README-DEMO.md      this file
var/logs/              api.log + web.log
.env                   auto-generated by find_ports.sh
```

## Knobs

| Env var | Default | Effect |
|---|---|---|
| `DECIPHER_DEMO_YES=1` | unset | non-interactive: auto-confirms every prompt |
| `DECIPHER_API_PORT`   | auto | override API port |
| `DECIPHER_WEB_PORT`   | auto | override dashboard port |
| `DECIPHER_DB_PORT`    | auto | override Postgres port |
| `DECIPHER_MAIL_PORT`  | auto | override Mailpit port |

## Caveats

- This is a **demo build**, not production. Authentication is prototype-grade and CORS is wide-open; do not expose the ports beyond localhost.
- Stripe / promo redemption / 90-day re-audit reminders / the real Squarespace bundle are not yet wired.
- Two existing audit versions: `media_sales_v1` (the canonical 34-question instrument with full scoring) and `master_v1` (legacy seed data with no scoring engine).

## Troubleshooting

| Symptom | Fix |
|---|---|
| `docker: Cannot connect to the Docker daemon` | Open Docker Desktop; the script will offer to wait for it. |
| Port already in use | `find_ports.sh` runs each boot and picks the next free port. |
| `psql: connection refused` after step 3 | Wait 10s and re-run; first-time Postgres init is slow. |
| Dashboard shows "Network error" | Check `var/logs/api.log`; API likely failed to import. |
| Want to nuke and restart | See "Resetting to a clean state" above. |
